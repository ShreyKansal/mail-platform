# Manage Contacts

## Add and Edit a Contact

Open **Contacts** and choose **Add contact**. Enter an email address and optional first and last names. Expand **Custom properties** when you need additional JSON data. Select **Save contact**.

Use the row's edit action to change a saved contact. The email address of an existing contact cannot be edited in this form.

## Find and Archive Contacts

Search by email or name. **Include archived** shows archived records. Archiving removes a contact from the active list; the row offers restoration when archived contacts are included.

## Subscription Preferences

**Unsubscribed from marketing** records a contact's preference. It does not block transactional messages. Only subscribe a contact with their permission. [Suppressions](SUPPRESSIONS.md) separately control addresses blocked from delivery.

## Import Contact Data

Choose **Import contacts** and provide the JSON array requested by the dialog. The import accepts up to 1,000 contacts. All rows are validated before any are saved, and duplicate addresses in the same batch are rejected. Review errors, correct the data and retry.
