# Find Your Way Around

## Workspace Navigation

The header contains your workspace menu, breadcrumbs, email search, help and notifications. The logo returns to Overview. Use **Collapse navigation** to give the content more room; **Expand navigation** restores it. On narrow screens, **Open navigation** opens a drawer.

The sidebar lists the pages available to your role:

| Area | Pages | Use it to |
| --- | --- | --- |
| Delivery | Overview, Emails, Analytics, Suppressions | Monitor sending and investigate recipient outcomes. |
| Content | Templates, Contacts, Broadcasts, Automations | Manage content, recipient details, campaigns and event-driven workflows. |
| Developer | Domains, API keys, SMTP credentials, Webhooks, API logs | Connect applications and configure sending. |
| Workspace | Settings, Exports, Documentation | Manage the workspace and find setup instructions. |

Only pages allowed by your role appear. Open the account menu at the bottom of the sidebar to change **Appearance** or sign out.

## Overview

Overview summarizes the selected period and shows recent email activity. Recipient counts and message counts measure different things: a message can have several recipients.

**Server accepted** means the recipient server accepted the message. It does not establish inbox placement.

The **Workspace setup** checklist appears while essential setup is incomplete. Add and verify a domain, create a sending key and submit your first email. A webhook is optional.

## Find an Email

Use **Search emails** in the header. Press Enter to open matching results on Emails. Use status and additional filters to narrow the list. Open a subject to inspect recipient states, timeline and available content.

## Help Without Leaving Your Task

The header help menu contains **Help with this page** when an article is available, **Documentation** and **Open API examples**. API examples open in a side sheet.

Documentation has a **Find by title** field in the left navigation. Inside an article, use **In this article** to jump to a section. On narrow screens, open the contents list above the article. **Back to workspace** returns to Overview.

## Workspace Settings

Open your workspace menu or **Settings** in the sidebar. **Usage** shows project activity and organization-wide sending limits. **Team** contains the workspace name and member list. **SMTP** manages credentials; **Integrations** connects applications; **Documents** shows documentation and compliance availability; **Billing** explains deployment billing; **Account** shows your profile and access. Editing depends on your permissions and deployment configuration.
